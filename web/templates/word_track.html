認知能力診斷報告 / Cognitive Diagnostic Report

LexiGaze 使用說明 / User Guide

1 第一步：影片相機校正與個人化訓練 (Calibration)

  1. 點擊左側「眼動追蹤」面板中的「相機校正與訓練 ↗」，這將開啟獨立的校正頁面。
  2. 輸入您的受試者 ID，然後點擊「開始」。
  3. 眼睛注視著螢幕上跳動的黑色圓點。鏡頭會同時錄影記錄眼球移動位置。
  4. 點點全部跑完後，系統將自動於後台開始訓練個人化模型（約需 2~3 秒）。完成後，您可以回到主頁面。

2 第二步：載入文章與啟用眼動追蹤 (Reading)

  1. 在左側「文件與分析」面板中上傳您的文件，或在下方「範例文件」直接選擇文章載入。
  2. 點選左側「眼動追蹤」面板：
    • 在「推論模型」選單中，選擇您剛剛訓練的個人化模型（如：anonymous_video_model）。
    • 點擊「啟用眼動推論」開啟視訊。此時會出現一個代表您視線的藍色注視點。
    • 確認「Gaze Mapping」也是開啟狀態，開始像平常一樣閱讀文章。

3 第三步：生成認知分析診斷報告 (Diagnostic Report)

  1. 閱讀完成後，打開右側的「認知能力診斷」面板。
  2. 輸入您的受試者 ID，並選擇文本的對應語言。
  3. 點擊「開始診斷認知能力」，系統會統計您的閱讀速度 (WPM)、回看次數、注意力專注度及閱讀疲勞度。
  4. 點擊「產生與儲存診斷報告」，即可產生精緻的文件認知能力評估報告，並提供個人化的學習建議。
小技巧：如果覺得藍色圓點不夠準確，請重新執行校正，並請確保您的臉部有足夠的光源，且眼鏡無眩光，這樣能獲得最佳的預測準確度。
效能提示 (Performance)：系統的眼動推論使用您的本機 CPU 運算。若您的電腦較舊（例如 2019 MacBook i5），建議在左側「眼動追蹤」→「效能設定」中，將「推論間隔」調高至 300–600 ms，可大幅降低 CPU 負擔並減少延遲感。

Performance tip: Gaze inference runs on your local CPU. On older machines (e.g. 2019 MacBook i5 with Intel Iris Plus), set the Inference Interval to 300–600 ms in the Eye Tracking panel to reduce CPU load and lag.
