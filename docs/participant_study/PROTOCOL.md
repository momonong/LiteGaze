# LexiGaze 受試者技術性 Pilot Protocol

狀態：`dry_run_only`。在倫理／豁免判定、研究聯絡人、外部效標授權、網路處理者核准、加密與留存設定全部完成前，不得招募朋友或建立正式邀請碼。

## 研究目的與邊界

本 pilot 先回答流程與量測工程問題：遠端相機校準是否可完成、動作改變下的校準品質是否足夠、閱讀流程能否可靠取得簽章答題結果與描述性品質摘要。它不驗證 CEFR、一般英文能力、一般閱讀能力、注意力、疲勞或認知能力，也不提供診斷。

目前題庫參數是專家初始值，尚未經真實樣本校準、信度、公平性／DIF 或外部效度驗證。pilot theta 只能在同一未校準題庫內作實驗性路由，不能轉換成能力標籤。

## 對象與規模

- 僅限年滿 18 歲、可自行同意者；不收精確年齡。
- 初始 pilot 應以流程可行性的小樣本為主；樣本數須在倫理文件與預註冊中另行決定。
- 邀請碼一次性使用。研究資料只保存系統產生的 pseudonym，不收姓名、電子郵件或永久裝置 ID。

## 受試者流程

1. 閱讀版本化資訊、必要風險、資料類別、退出方式與聯絡資訊。
2. 主動勾選全部必要聲明並通過三題理解確認。
3. 下載同意收據與一次性退出碼。
4. 系統檢查：安全連線、相機 API、螢幕大小與網路。
5. 13 目標、五個姿態／距離區塊的 motion-diverse 校準。
6. 伺服器品質閘；個人化只在 CPU 執行。成功或失敗都立即清除校準影像；異常中斷最遲依核定 TTL 清除。
7. 4–6 輪固定排版英文短文；每篇三題。每輪文章指派與結果 token 綁定 assessment、受試者、輪次、protocol 與 item-bank 版本。
8. 顯示有界限的 session 結果與退出資訊。

閱讀期間相機影格只逐幀進記憶體做視線推論，不寫入研究儲存空間；僅保留描述性摘要。v1 不錄製完整影片。

## 主要品質結果

- 招募、同意、系統檢查、校準、閱讀與退出各步完成率。
- 校準 motion coverage、有效樣本數、分組驗證誤差及清除成功狀態。
- 每輪答題數、文章／construct coverage、閱讀時間與眼動推論品質。
- 技術失敗、重試、退出與資料刪除事件。

## 停止條件

任何一項成立即停止新增受試者：同意版本或目的改變、原始影像超過 TTL、退出無法完整刪除、公開管理 API 可被存取、HTTPS／加密失效、題目／結果 token 可跨受試者重放、未核准的第三方收到 request body，或發生未列入同意書的風險。

## 防止 overfit 與資料污染

- 朋友資料在 pilot 階段只用於流程與品質可行性，不用來宣稱最終模型效能。
- 在第一次使用真實受試者結果調參前，先冻结 participant split 與 item/text split；同一受試者、文章平行形式或近重複文章不可跨 split。
- 題庫開發、模型選擇與最終評估分離。任何被看過並用來改系統的題目／受試者都屬 development，不得再報為 holdout。
- 外部效標必須在招募前選定、確認授權並寫入預註冊；不得依 pilot 結果挑選最有利的效標。
- 排版在能力估計階段固定；排版實驗另用 matched text 與隨機／counterbalanced 設計。
- 所有偏離預註冊的決策記入 `PROGRESS_LOG.md`，以探索性結果報告。
